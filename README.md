# Lantern previews

Sample documents generated by [Lantern](https://github.com/reubenbubu/lantern) from the OpenWMS test set, published with GitHub Pages: https://reubenbubu.github.io/lantern-preview/

Each analysis run has its own folder under `runs/` with its documents, screenshots and notes; the root page lists the runs, newest first. The summary text was written by DeepSeek's chat model through Lantern's Anthropic-compatible provider; Lantern is designed for Claude, so wording quality may differ.
